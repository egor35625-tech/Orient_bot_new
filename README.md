# Orient Marketplace (Telegram Mini App)

Маркетплейс по Беларуси: объявления пользователей и магазины с модерацией.

## Запуск

1. Python 3.11+, `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `ADMIN_IDS`, `WEBAPP_URL`.
3. `uvicorn app:app --host 0.0.0.0 --port 8000`

При старте таблицы создаются/дополняются автоматически (недостающие колонки добавляются сами),
данные **не удаляются** — удалять `orders.db` после обновлений больше не нужно.

## Чтобы данные не пропадали после рестарта

* Локально: SQLite лежит в `orders.db` рядом с проектом (путь больше не зависит от папки запуска).
* Все загруженные фото (объявления, логотипы, отзывы, фото заказов) хранятся в базе данных, а не на диске — они переживают деплой, если `DATABASE_URL` указывает на PostgreSQL.
* На хостинге (Render и др.) диск временный — SQLite стирается при каждом деплое.
  Используйте PostgreSQL в `DATABASE_URL` и постоянный диск для `UPLOAD_DIR`
  (готовый пример — `render.yaml`).

## Логика

* **Регистрация** = указать свой @username в Telegram (уникален). Без неё нельзя создавать объявления,
  заявки на магазин, покупать и оставлять отзывы.
* **Объявления**: только продажа, категории выбираются в фильтре. Телефон необязателен: «только сообщения» или
  «сообщения и звонки». Редактирование и удаление — в «Мои объявления».
* **Модерация объявлений**: любое новое объявление (частное и от магазина) получает статус `pending` и не видно в ленте,
  поиске, магазине, чатах и «Поделиться», пока модератор не нажмёт «Одобрить». Правка названия, описания, фото, категории
  или телефона уже опубликованного объявления отправляет его на повторную проверку (цена, размеры, город и т.п. — без неё).
  Отклонённое объявление автор видит в «Моих объявлениях» с причиной; после правки оно снова уходит на проверку.
  Уже существовавшие до обновления объявления остаются опубликованными.
* **Уведомления модераторам** (всем из `ADMIN_IDS` и добавленным через панель):
  * в Telegram приходит карточка объявления с фото и кнопками «✅ Одобрить» / «❌ Отклонить» (причину бот спросит отдельным
    сообщением); команды `/queue` — очередь, `/admin` — счётчики, `/cancel` — отмена ввода причины.
    Модератор должен хотя бы раз написать боту `/start`, иначе Telegram не даст боту писать первым;
  * в `/admin` вкладка «📋 Объявления» со счётчиками на вкладках; панель каждые 15 секунд проверяет новые запросы и показывает
    всплывающее уведомление.
* **Магазин**: один на пользователя. Создание и любое изменение (включая аватар) идут через модерацию.
  Контакты, город, доставка и самовывоз магазина подставляются во все его объявления автоматически.
  Объявления в магазин добавляет только владелец.
* **Модераторы** (`ADMIN_IDS` + добавленные через API) в `/admin`: заявки, блокировка (на N дней / навсегда),
  разблокировка и удаление магазинов.
* Страна — только Беларусь, шрифт — моноширинный.

## Оформление (Orient)

* Цвета: Burgundy `#800020`, Cream `#FFF5E1`. Тема «Orient» включена по умолчанию, есть тёмная и светлая.
* Шрифт интерфейса — SF Pro Display (на Android/Windows подставляется Inter).
* Фирменный шрифт **Soledago** (логотип, заголовки): положите файл в `static/fonts/` под именем
  `Soledago.woff2`, `Soledago.otf` или `Soledago.ttf`. Пока файла нет, используется похожий Shrikhand.
* Логотип и иконки — `static/img/`. `bot-avatar.png` — аватарка для бота в @BotFather (/setuserpic).
* Избранное хранится на устройстве пользователя (localStorage).


## Ссылки «Поделиться» (объявление и магазин)
* По умолчанию ссылка вида `https://t.me/<бот>?start=item_5` (или `shop_3`): бот отвечает карточкой и кнопкой «Открыть», которая ведёт именно на объявление или магазин. Ничего настраивать не нужно.
* Чтобы страница открывалась сразу, без чата с ботом: в @BotFather создайте приложение (`/newapp`), укажите ссылку на сайт и добавьте в переменные окружения `MINIAPP_SHORT_NAME=<короткое имя>`. Ссылки станут `https://t.me/<бот>/<имя>?startapp=item_5`.
* Состояния товара: «Новое с биркой», «Новое без бирки», «Отличное», «Хорошее», «Нормально», «Плохое». Старые «Как новое» и «Б/у» при запуске автоматически превращаются в «Отличное» и «Хорошее».
